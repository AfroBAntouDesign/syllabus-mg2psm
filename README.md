# 📚 Syllabus MG2PSM

Site web de consultation et de téléchargement du syllabus du **Master professionnel en Génie des Procédés Pharmaceutiques et Sciences du Médicament** (MG2PSM) — FMSB, Université de Yaoundé I.

## 🎯 Fonctionnalités

- 📖 Consultation du syllabus complet (M1 + M2)
- 🔍 Recherche et filtres par semestre / parcours
- 📱 Design responsive (mobile, tablette, desktop)
- ⬇️ Téléchargement du PDF officiel
- 🌙 Thème sombre premium
- 🎨 Identité visuelle AfroBantou design
